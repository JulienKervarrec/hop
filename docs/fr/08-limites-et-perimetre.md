# 8. Limites et périmètre

Ce parcours décrit les mécanismes lisibles dans le monorepo Hop : bridge, avances de bonder, wrappers AMM, cycle de transfert, preuves de retrait, SDK et watchers du nœud. Il ne constitue ni un audit de sécurité, ni une garantie de liquidité, ni une validation des déploiements actuels.

La branche develop observée contient une branche v2 annoncée comme en développement, dont le README du SDK indique une documentation publique encore très réduite. Les lecteurs doivent donc vérifier les adresses, réseaux, versions et contrats avant toute intégration.

Aucune nouvelle installation, compilation, exécution de test ou déploiement n’a été effectué pour ce parcours : le contenu repose sur la lecture statique de README, de la structure des packages et des modules SDK/node. Pour approfondir, consulter la suite de tests du dépôt et la documentation officielle Hop.

Retour au [sommaire du parcours](README.md).
